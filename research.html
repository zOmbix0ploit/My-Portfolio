STUDY 01 // GEOMETRY SDF · RAYMARCHING

Signed Distance Field Sculpted Manifolds

Continuous implicit mathematical representations of 3D forms. By mirroring the depth axis and applying quaternion rotation, particles are constrained to smooth, organic hollow ring surfaces with zero polygonal rasterization artifacts. 

float sdfShape(vec3 p) {
  // Mirror depth axis for symmetric soft seam
  p.z = sqrt(p.z * p.z + 0.0215) - sqrt(0.012);
  
  // Quaternion rotation by (0.5, 0.5, 0.5, 0.5)
  vec3 qv = vec3(0.5);
  p = p + 2.0 * cross(qv, cross(qv, p) + 0.5 * p);
  
  vec2 ring = vec2(length(p.xz) - 0.42, p.y);
  return length(ring) - 0.16 + sin(p.x * 5.0) * 0.035;
}

STUDY 03 // VECTOR FIELDS BRIDSON CURL NOISE

Divergence-Free Vector Field Turbulence

Analytic curl noise derived from three sine-sum potentials. Guaranteed zero divergence means particles swirl in natural fluid currents without clumping or collapsing into localized singularities. 

vec3 curlNoise(vec3 p) {
  const float e = 0.01;
  vec3 dx = (potential(p + vec3(e,0,0)) - potential(p - vec3(e,0,0))) / (2.0 * e);
  vec3 dy = (potential(p + vec3(0,e,0)) - potential(p - vec3(0,e,0))) / (2.0 * e);
  vec3 dz = (potential(p + vec3(0,0,e)) - potential(p - vec3(0,0,e))) / (2.0 * e);
  return normalize(vec3(dy.z - dz.y, dz.x - dx.z, dx.y - dy.x));
}
STUDY 04 // COMPUTE WEBGPU · WGSL

WebGPU Compute Shader Pipelines

Advancing from WebGL 2.0 to raw WebGPU compute passes. Direct GPU memory access via storage buffers enables simulation of 1,000,000+ spatial points with hardware-level memory barriers and zero CPU bottleneck. 

@compute @workgroup_size(64)
fn simulateParticles(@builtin(global_invocation_id) id: vec3<u32>) {
  let index = id.x;
  if (index >= particleCount) { return; }
  var pos = particles[index].position;
  pos += curlVector(pos * 0.1) * deltaTime;
  particles[index].position = pos;
